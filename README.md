# 서기관의 급보철 (Diplomatic History Game)

외교사를 **읽는 대신 겪게 만드는** 브라우저 게임입니다.
1618년 베스트팔렌에서 1991년 소련 해체까지, 각 시대 외교 현장의 **말단 서기관**이 되어
인물들에게 말을 걸고 급보를 처리합니다.

> "가톨릭 왕국 프랑스가 왜 개신교 편에 섰는가?"
> 당신이 고른 건의는 **실제 역사와 대조되고**, 틀리기 쉬운 지점은 **시험의 함정으로 정리**됩니다.

**11개 단원 · 급보 149건 · 확인문제 다수.** 설치도 서버도 필요 없습니다. `index.html` 하나입니다.

## 하는 법

1. 위 링크를 열거나, `index.html` 을 내려받아 브라우저로 엽니다.
2. 목차에서 단원을 고르고 [시작하기]
3. 방향키(모바일은 화면 버튼)로 이동 → 인물에게 **말걸기** → 대화 → **건의 선택**
4. 선택 즉시 실제 역사와 대조한 해설이 나오고, 사료 요약·함정·확인문제로 이어집니다

진행 기록은 그 브라우저에만 저장됩니다. 서버로 아무것도 전송하지 않습니다.

## 구성

| 편 | 단원 |
|---|---|
| 제1편 유럽 외교사 | 17·18세기와 나폴레옹 전쟁 / 빈 체제와 회의외교 / 크리미아전쟁과 이탈리아·독일 통일 / 비스마르크 동맹체제 / 삼국동맹과 삼국협상 / 1차 대전과 베르사유체제 |
| 제2편 냉전시대사 | 2차 대전과 냉전의 형성 / 데탕트와 냉전의 해체 |
| 제3편 동양 외교사 | 중국(아편전쟁~의화단) / 일본(개국~태평양전쟁) / 조선(개국~병합) |

각 단원 안에는 **상황 브리핑 · 지도 · 전세표/통계 · 급보철(오답노트)** 패널이 들어 있습니다.

## 왜 이렇게 만들었나

외교사는 조약 이름과 연도가 끝없이 나오는 과목입니다. 그런데 정작 시험에서 갈리는 건
"1차 파리조약은 1792년 국경, 2차는 1790년 국경" 같은 **한 글자 차이**입니다.
외워서 넘기려 하면 계속 헷갈리고, 이유를 알면 안 헷갈립니다.

그래서 **당시 사람의 자리에 앉혀 판단하게 만들고**, 고른 뒤에 실제 역사와 맞춰 보게 했습니다.
틀린 선택지에도 "왜 그럴듯한데 틀렸는지"를 붙였습니다. 함정 목록은 실제로 헷갈리는 짝들만 모았습니다.

## 만든 방법

- 순수 HTML/CSS/JavaScript 한 파일. 외부 라이브러리·빌드 도구·서버 **전부 없음**
- 맵은 캔버스에 직접 그리는 타일 방식, 데이터(단원·대화·선택지·해설·퀴즈)는 모두 코드 안의 객체
- AI(Claude)와 함께 만들었습니다. 사료 정리와 문장 다듬기에 썼고, 구성과 판단은 직접 했습니다
